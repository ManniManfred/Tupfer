Tupfer Designer herunterladen

Neueste Version für Windows, Linux und macOS

Die Desktop-Version kann alles, was die Web-App kann, und läuft ohne Internet. Dazu kommen das Programmieren in C#, die Windows-Sprachausgabe und das Speichern auf den Stift unabhängig vom Browser. Ohne Installation geht es weiterhin im Browser: Tupfer Designer im Browser öffnen.

Für dieses Gerät

Windows

Windows 10 und 11 (64 Bit)

Setup herunterladen.exe

Das Setup ist nicht signiert: Meldet Windows „Der Computer wurde geschützt“, auf „Weitere Informationen“ und dann „Trotzdem ausführen“ klicken.

Für dieses Gerät

Linux

64 Bit (x64)

Paket herunterladen.deb für Debian, Ubuntu, Mint … AppImage herunterladenfür alle Distributionen, ohne Installation

Das AppImage in den Eigenschaften als „ausführbar“ markieren (oder chmod +x Tupfer-Designer-Linux-x64.AppImage) und starten.

Für dieses Gerät

macOS

macOS 12 oder neuer

Für Apple-ChipM1, M2, M3 … (.dmg) Für Intel-Prozessor.dmg

„Tupfer Designer“ in den Ordner „Programme“ ziehen. Die App ist nicht von Apple beglaubigt: beim ersten Start per Rechtsklick → „Öffnen“ bestätigen.
